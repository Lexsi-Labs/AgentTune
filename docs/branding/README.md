# AgentTune brand assets

The logo is a small robot head (two eyes, a headset, an antenna) followed by the "AgentTune"
wordmark.

## Files

| Asset | File | Use |
|---|---|---|
| Logo, light bg | [`agenttune-lockup-light.png`](agenttune-lockup-light.png) | headers on light backgrounds |
| Logo, dark bg | [`agenttune-lockup-dark.png`](agenttune-lockup-dark.png) | headers on dark backgrounds |
| Wordmark, light bg | [`../assets/agenttune-logo-black.png`](../assets/agenttune-logo-black.png) | docs site header/hero on light backgrounds |
| Wordmark, dark bg | [`../assets/agenttune-logo-white.png`](../assets/agenttune-logo-white.png) | docs site header/hero on dark backgrounds |

For a themed logo in Markdown, use GitHub's `<picture>` with both lockups. See the top of the
[README](https://github.com/Lexsi-Labs/AgentTune/blob/main/README.md).

## Color

- Wordmark: white (dark bg) or ink black (light bg)
- Accent: signal-orange `#f2530e` on the "Tune" half of the wordmark and the mark's eyes/ears
- Docs site: plain black/white wordmark in the header and hero; the site's only brand color is signal-orange `#f2530e`, applied via CSS

## Usage

- **Do** keep clear space around the logo roughly equal to its own icon width.
- **Don't** recolor the orange accent or stretch/rotate the logo.
